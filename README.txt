방문객 주소
https://sorae-waiting.vercel.app/

관리자 주소
https://sorae-waiting.vercel.app/admin

업데이트 방법
1. GitHub sorae-waiting 저장소 기존 파일을 모두 삭제합니다.
2. 이 압축파일을 풀고 내부 파일 전체를 GitHub에 업로드합니다.
3. Commit changes를 누르면 Vercel이 자동으로 재배포합니다.
4. Firebase Authentication > 사용자에서 운영자 이메일/비밀번호 계정을 생성합니다.
5. /admin에서 로그인 후 '체험 4종 초기 생성'을 한 번 누릅니다.

실제 행사 전 필수 테스트
- 여러 휴대폰 동시 접수
- 운영자 5팀 호출
- 대기 취소
- 접수 마감/재개
- 브라우저 종료 후 재접속
- 현장 통신 장애 대응
